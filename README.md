# جسور — منصة الترابط الاجتماعي

نموذج أولي تفاعلي لمنصة تساعد على تعزيز الترابط الاجتماعي عبر الأنشطة المحلية، والتواصل بين الأجيال، ومتابعة التقدم الأسري.

## التشغيل

افتح ملف [جسور — منصة الترابط الاجتماعي.html](جسور%20%E2%80%94%20منصة%20الترابط%20الاجتماعي.html) مباشرةً في متصفح حديث. لا يتطلب النموذج تثبيت حزم أو تشغيل خادم.

## الأقسام

- **الرئيسية:** مؤشر الترابط الاجتماعي والأنشطة المقترحة.
- **جسر الأجيال:** فرص المساعدة والتطوع ومكافآتهما.
- **الأسرة:** مؤشرات أفراد الأسرة وإعداداتها.
- **حسابي:** الإنجازات والإعدادات وإعادة ضبط بيانات العرض التجريبي.
- **المنصة:** عرض مبسط لمكونات النموذج.

## ملاحظات

- التسجيل في الأنشطة، المساعدة، والإعدادات تفاعلات تجريبية.
- تُحفظ حالة العرض في `localStorage` على الجهاز والمتصفح الحاليين؛ لا يرسل النموذج هذه البيانات إلى خادم.
- يتصل النموذج بخط **Tajawal** من Google Fonts لتحسين عرض النص. عند عدم توفر الإنترنت، يستخدم خطاً بديلاً.
